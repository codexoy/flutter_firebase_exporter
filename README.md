A Flutter utility for exporting Firebase data with model mapping capabilities.

**Structure:**
- `/csvmaker` - CSV export functionality
- `/fbase` - Firebase utilities
- `/models` - Data models
- `/repo` - Repository layer with model mapping

**Features:**
- Firebase data export
- Model mapping utilities
- CSV generation
- Repository pattern implementation

**Recent Updates:**
- Added Slice support
- Refactored model structure
- Enhanced model mapper functionality
